# HermiteTwin

Project website for **HermiteTwin: Bicubic Hermite Shell Digital Twins for Contact-Rich Deformable Manipulation**.

- Website: https://kangruiz.github.io/hermitetwin/
- Paper: https://openreview.net/forum?id=0QXB9nl5QA

This repository contains the static project page, paper figures, videos, and citation. The source folder for GitHub Pages is the root of the `main` branch. No build step is required.

To preview locally, run `python -m http.server 8000 --bind 127.0.0.1` from this directory.
